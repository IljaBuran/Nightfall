# Nightfall

<sub>This project was created for educational purposes and possible bachelor thesis.</sub>

Nightfall is yet another game engine with native editor. 

The main idea is to create as much as I can from scratch. But third party libraries will be used to save work that I certainly **WILL NOT** be able to do efficiently, e.g. Dear ImGui, AvalonDock, asset loading libraries etc...

> [!IMPORTANT]
> Some Editor code may be generated by LLMs as I have quasi zero WPF experience and don't want to dive too deep in this topic and spend a lot of debugging.
> When it comes to engine, every line is written BY HAND, but for extensive research purposes and debugging LLMs are going to be fully utilized.

## Nightfall Engine

Engine is written in C++23 and created with simple, but crucial concepts:

**Performance**:<br> 
Core systems and hotpaths are (at least tried to be) approached with data-oriented, cache-friendly design.

**High Modularity**: <br> 
"Use only what is needed". Core of the Engine will be as lightweight as possible and modules (chosen by user) are fit for application's purposes.

## Nightfall Editor

The Editor is made with C# and WPF, thus Windows only. 

### Editor as separate process

I aim for Editor to be as independant from Engine, so it is not impacted by Engine crashes and avoid lost work.

### Editor&harr;Engine Communication via TCP/IP
Editor communicates with Engine (and viceversa) via TCP/IP protocol.
